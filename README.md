# Выездной сервис коммунальной техники

Статический сайт выездного сервиса и каталога запчастей для мусоровозов. Проект перенесён с Tilda на самостоятельные HTML, CSS и JavaScript без внешних зависимостей конструктора.

## Страницы

- `index.html` — главная страница и общий каталог;
- `hidromak.html` — каталог запчастей HIDRO-MAK;
- `katmerciler.html` — каталог запчастей KATMERCILER.
- `product.html?part=kat-monitor` — подробная карточка запчасти (12 позиций в `products.js`);
- `products.js` — описания, подтверждённые каталожные характеристики и галереи;
- `product.js` — просмотр фотографий, увеличение и заполнение заявки выбранной деталью.

Карточки доступны по изображениям, названиям и кнопкам «Подробнее» в каталоге. Для добавления позиции дополните `products.js` и добавьте ссылку `product.html?part=идентификатор` в соответствующий каталог. Изображения должны быть локальными файлами в `assets/`.

Технические параметры, которых не было в исходном каталоге, обозначены как требующие уточнения. HIDRO-MAK содержит группы подбора и каталожные схемы, а не подтверждённые отдельные товарные позиции с артикулами. Цена, наличие и срок поставки не вымышлены: указано «По запросу».

## Локальный запуск

Откройте `index.html` напрямую или запустите любой статический HTTP-сервер из корня проекта.

## Ограничения демонстрации

Форма заявки работает в демонстрационном режиме и не отправляет данные. Для рабочего сайта необходимо подключить обработчик формы или CRM.

Оформление оплаты и корзина отсутствуют: каталог предназначен для запроса и подбора запчастей. Телефонные и почтовые ссылки работают.

Публичная демонстрация закрыта от поисковой индексации через `robots.txt` и метатеги `noindex, nofollow` на всех HTML-страницах.
